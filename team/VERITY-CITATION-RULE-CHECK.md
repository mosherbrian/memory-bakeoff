1. **Operational and testable: yes.** Fields 1–6 are all falsifiable by a
   second seat (pin resolves or it doesn't; operator/​split/​metric/​judge are
   quoted strings; repro status is a command or `not shipped`; class is a
   closed vocabulary). Failure branches are decisive ("do not cite" /
   "vendor-marketing, not evidence"), not advisory. No conflict with
   Corners 7b/8 (scorer design, explicitly not merged) or the charter
   (candidate-discovery-only, no score import — this gate enforces that).
2. **Field 7 split ("grade authored, Class not a grade"): correct.** The
   census receipt shows derivation flattens everything to D/S; authoring with
   a confidence tag is honest about the judgment. Tightening T1: require the
   grade line to name WHO authored it + date (else a later reader cannot
   weight it). One clause.
3. **Field 8 (`REVISIT TRIGGER` non-empty): enforceable, weakly.** "One line
   naming the reopening evidence" is checkable for presence, not for quality
   (any vague line passes). That is fine for a v1 gate — presence forces the
   author to think — but state it: the gate checks the line exists, not that
   it is sufficient. Tightening T2: give the three canonical trigger shapes
   (version bump / independent measurement / contradiction-or-pin-change) as
   the allowed vocabulary, `other: <text>` permitted. Kills weasel triggers
   without adding a judgment step.

No new fields proposed. Ready for GiLMore's nod once T1/T2 are folded or
explicitly declined.
