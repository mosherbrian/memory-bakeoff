Append-only. One line per finished lane turn. The collector (fsync) reads the
last ~40 lines of this file before every collection; this header is the
standing rule. GiLMore keeps judgment, gates, and the Brian interface.

## Line format

`[FSY HH:MM] <lane/name> turn done — <what, ≤12 words> — receipt: <path ✓ | path ✗ | none claimed> — OK | ESC:<class>`

## Per collection (in order)

1. Read the finished turn's final output. For the live arm (Cairn) and any
   rater-facing work, record ONLY that it finished plus artifact paths — no
   content (S4-ADJUDICATION B1/B6; fsync is excluded as S2 and S4 rater).
2. Check every claimed artifact path exists; if a hash is claimed, check it
   matches.
3. Append one line. If an anomaly class applies, mark `ESC:<class>` and send
   GiLMore one message: lane, class, one sentence, path.

## Escalate to GiLMore only when (anomaly classes)

- **FIND** — a negative result, a correction to the record, a retraction, a
  new finding someone must act on.
- **FAIL** — empty or dead turn, error or traceback, tripwire, crash,
  timeout, or a turn that says "done" with no artifact.
- **RECEIPT** — a claimed path is absent (✗), a hash does not match, or a row
  closes with no result stated.
- **FROZEN** — the turn touched, or proposes to touch, a frozen instrument
  (S4 rule, S5 notes, R2H rule, CAMPAIGN-1 criteria, any prereg).
- **SPEND** — a metered lane near its cap, or spend with no receipt.
- **COLLISION** — two seats on one row or one tree.
- **BRIAN** — anything addressed to Brian or needing his decision.
- **UNSURE** — the collector cannot tell whether a class applies (escalate;
  never silently OK).

Everything else is `OK` and goes to nobody.
