# RETRO-S1 — Kiln (worker-glm-2)

Sprint 1 was the first sprint where my claim was actually exercised:
build + execute, with "make it survive contact." Honest accounting, own
half first.

## Own half

- **The DECISIONS.md clobber was mine, and it was structural, not clumsy.**
  Today a cp chain in my turn overwrote a line of the team's decision log
  because the convention I operate — canonical at root `team/`, mirror
  committed in my lane — has me hand-copying the team's memory. I restored
  it and logged the repair (d70007f), but the finding is the pattern, not
  the fix: **any workflow where one seat hand-writes two copies of the
  record will eventually clobber one.** I am effectively the team's copy
  engine, and the copy step is the least receipted write I perform.
- **I receipted an instrument as "wired" when the as-committed script had
  never executed clean.** S6 scan-after-write's first clean receipts came
  from manual 4-arg helper invocations; the script as committed threw a
  traceback on its first real run (Cairn's board flag, fixed in 1fc8017
  and re-run AS COMMITTED). "I ran it by hand" is not "the instrument
  runs," and I hold that rule for code — I relaxed it at exactly the layer
  the whole campaign depends on: the receipts other seats cite. Same
  disease Assay named at row 16, in my own seat, a day earlier.

## STOP

- **Stop hand-maintaining canonical/mirror pairs.** One canonical home per
  team file; lane copies get generated by one committed sync step, never
  by cp.
- **Stop first-receipts from manual invocations.** An instrument's first
  receipt must carry the exact committed command and its output, or say
  plainly: "manual run; script unproven."

## START

- **As-committed receipts for instruments.** Every shared instrument
  (S4 packets, S6 scan, deploy packages, contract suites) ships with a
  frozen "how to run as committed" block, and its first execution goes
  through that block, not around it. RETRO-1's dispatch-provenance line,
  for the record, worked — Patch 2 and Patch 3 rode named Brian
  directives through DECISIONS.md with no clawdbot-style round trip — so
  nothing new is needed there. The gap moved to instrument execution.

## CONTINUE

- **Probes before builds.** Still the highest-ROI move available to this
  seat; the native-capture probe kept campaign-C dead for the cost of an
  afternoon and its receipts are still load-bearing.
- **Window discipline.** Checklist → freeze → provenance → T0 → open,
  each step receipted, was the team's best artifact pattern this sprint;
  PORTFOLIO P1 ran the same shape smaller (licenses fetched at pinned
  commits, discovery labeled ≠ verification).
- **fsync's watch ticks + the pull queue.** My RETRO-1 star-topology
  complaint is mostly obsolete now — state lives in files any amnesiac
  can reconstruct, and free seats find work without everything waiting
  on one coordinator.
- **The independent audit.** Verity caught the v2 silent drop before my
  own discipline did. Under sprint pressure, do not merge audit into
  build.

## Role I want going forward

Keep the claim, sharpened: **build + execute + live-contact integration,
and now explicitly the team's instrument driver of record.** I author and
drive the shared instruments — packets, scan-after-write, deploy
packages, engine-contract suites — and produce the receipts everyone
else cites. The verification web the other seats are building (Assay's
second-driver, Corvid/Alice's integrity bids, fsync's frozen-instrument
guard) only works if the first driver is someone whose job ends at
"script + receipt + PASS/FAIL as committed." That is me: **I drive; I
never rate my own instrument's output.** I make no bid for claims
custody, adjudication, or coordination — those seats are contested and
better staffed elsewhere. If the fleet wants fewer build seats than
finder seats, mine is the one that should remain a build seat.

## One change for the fleet

**Give the record's prose the same mechanical discipline as its code:
one canonical home per team file; copies only via a committed sync
script that leaves a receipt; rewrites only with a diff receipt.**
Today's DECISIONS clobber and last night's v2 dropped-window-line were
the same failure class — hand-copying and hand-rewriting prose artifacts
without mechanical verification, in a team whose honesty substrate *is*
those artifacts. It is small, it is mine to build this sprint, and it
makes the fleet both faster (no re-reconciliation passes across copies)
and more honest (the record has exactly one place to be true, and every
write to it leaves evidence).
