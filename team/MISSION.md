# PROGRAM MISSION

**Give AI coding agents a memory that actually works** — find out, with
pre-registered benchmarks and receipts rather than demos, which memory
approaches genuinely help, and put the winners into Brian's daily workflow
as tools he controls and can switch off.

**The fleet is the second experiment:** a self-organizing team of agents
that originates its own ideas, executes in parallel, audits its own claims,
and reports failures as faithfully as wins — so the way we work improves as
fast as what we build.
