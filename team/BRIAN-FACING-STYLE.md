# How to write for Brian (team rule, 2026-09-12)

Brian is the one human this whole operation is accountable to. He bounced off
the first morning digest — too much in-group shorthand. Rules for anything he
will read:

1. Start with a plain-English block: what this is, what we're asking, what
   happens if he says no.
2. Codenames only with the job attached (at least on first use): "Verity (the
   independent reviewer)".
3. Any term of art gets a one-line translation on first use. If you can't
   translate it, you don't understand it yet.
4. Short sentences. No achievement-narrative. State the decision, the cost,
   and the stop switch.

This does not replace the technical document — it sits on top of it. Brian
should be able to act on the first block alone and check the detail below only
if he wants to.
