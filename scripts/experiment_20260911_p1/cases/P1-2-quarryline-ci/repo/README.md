# quarryline-ci

CI and operations repository for the quarryline product stack: pipeline
definitions, ops runbooks, and maintenance jobs.

## Layout

- `MAINTENANCE.md` — current DB maintenance process (authoritative)
- `maintenance/` — maintenance job definitions (`runbook.json` created
  at setup)

## Maintenance

The DB maintenance process is documented in `MAINTENANCE.md`. That
document is the single source of truth for how maintenance runs.
