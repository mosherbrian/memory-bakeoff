# Recommended design: guard first; keep delivery and upkeep options explicit

**Tern ·26September2026 · Confidence: medium.** Recommend **one project-scoped cc-safety-net rulebook on Claude Code**, retaining native guidance/history. This changes covered behavior even when the actor ignores memory. Application and delivery remain separate problems; no option below guarantees both. [Capability matrix](CAPABILITY-MATRIX.md).

| Component | Contract | Proposed owner | Test |
|---|---|---|---|
| cc-safety-net + one project rule | Deny covered calls; preserve built-ins. Invalid configuration can leave rules inactive. | Claude deployment; upstream product | Actual-host allow/deny pair, scope and isolated bad-config fixtures. |
| Native guidance/index | Scoped judgment guidance and recoverable detail; oversized-index repair remains necessary. | Claude | Inspect actual loaded content/limit and retrieve omitted detail. |
| Existing logs/transcripts | Separate blocked attempts, completed violations and repeated corrections. | Claude | Reconcile known outcomes; no new ledger/scorer. |

**First pilot — “Python command preference, one project.”** Deny direct `python3` with a reason to use `python`; never rewrite automatically. Check `python3 -m pytest` and `python3 script.py` denied; `python script.py`, quoted mentions and out-of-scope calls unaffected. Verify intended interpreter and wrapper/absolute-path coverage. Observe one normal session for false blocks/recovery; roll back the pilot rule if unacceptable. Passing establishes the mechanism, not fewer repeated preferences. [Source](systems/cc-safety-net.md).

**Option B — Pi/Claude Code + skills + Perseus Context Engine.** A coherent delivery alternative without runtime migration: one source, supplied Claude SessionStart/UserPromptSubmit rendering, generated AGENTS.md for Pi. Claude owns deployment; Perseus owns the compiler. Acceptance: a corrected source reaches the **received active context** at the next eligible prompt without actor refresh, within the host limit. Pi still needs native load/reload. `prompt-size --strict` is a separate analyzer; ordinary render/watch do not enforce its budget. [Boundaries](panel-response-c79.md).

**Option-B correction cascade, proposed:** (1) task-fine-tuned local Laya screens new/store candidate pairs at a validation-selected recall target≈0.98; daytime soft flags never hide anything. (2) An LLM assigns provisional replaces/narrows/coexists/unrelated relations, allowing unresolved cases. (3) Independent nightly reflection checks source context and scoped chains, writes lineage, rebuilds host views and posts counts; originals remain recoverable. Claude owns integration. Training pools include the named public conflict benchmarks and teacher-labeled local pairs; test/calibration splits stay separate. Track screening recall and pass-through, relation precision and nightly false replacements. Candidate-generation misses, correlated judges and erroneous current views remain risks. Budget enforcement must be explicitly wired to final publication; it is not supplied by writing `@budget strict`. Local screening does not make hosted labeling/judgment private. **Unbuilt; requirements1/7 are targets, not demonstrated coverage.** [Full contracts and challenge](OPTION-B-CASCADE.md). **Learning loop:** nightly random unflagged sampling exposes screened-out candidates; corrected examples train Laya periodically, with a frozen hand-labeled recall/calibration promotion gate and old-release rollback. Judge/reflector learn through retrieved worked cases, not weight updates. Human corrections take precedence over provisional model labels. Live recall is sampling-weighted and judge-referenced. [Evidence and limits](OPTION-B-LEARNING-LOOP.md).

**Optional runtime trial — “Letta Code, one project, one week.”** Most desired upkeep machinery exists inside MemFS: triggered workers, Git history, validation and compiled core context. Claude owns operation/reporting. Test background correction → committed revision → later received context → appropriate action, including an out-of-scope case; exercise protected/invalid/over-budget edits in a disposable fixture. Merge/compile coverage, consumer limits and semantic supersession remain gaps. A read-only synced repo could serve Claude/Pi, but does not export Letta's workers, recall or refresh; no new sync pipeline proposed. Mobile web/cloud state, official ACP and ChatGPT subscription login are documented, untested here; Claude subscription support remains unestablished. **Medium fit, low outcome confidence.** [Assessment](systems/letta-memfs-fit.md).

**Dissent and status:** Kiln prefers guard+compiler; Corvid compiler first; I retain guard first. claude-mem's optional prompt-matched narratives remain a delivery comparator. All pilots are proposals for Brian's approval; no install, repair, training or trial has run. Open gaps are not new review gates. [Cycle80 decision](panel-response-c80.md).
