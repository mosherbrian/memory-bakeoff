# Recommended design: enforce scoped rules; retain judgment memory

**Tern ·26 September2026 · Confidence: medium.** Adopt **cc-safety-net with one project-scoped rulebook**, using its existing host integrations. Retain native memory and transcripts for judgment and recovery. Start with Claude Code; extend the same policy to Pi after testing its adapter. Local executors without a covered host remain explicitly outside enforcement.

**Why this choice:** agent-owned notes already exist and fail. A pre-execution guard can change the result when the actor ignores a saved lesson. The claude-mem comparison confirms supplied capture/injection, not independent command interception or measured benefit here. ReMe/Hindsight/Pi reflection remain alternatives for delivery, not reasons to add a service now. [Evidence and limits](panel-response-c69.md).

**Named first pilot — “Python command preference, one project.”** Brian approves one bounded pilot on one selected project and Claude Code installation. Add a declarative rule rejecting direct `python3` invocations with a reason to use `python`; do not rewrite commands automatically. `python3 -m pytest` and `python3 script.py` are deny cases; `python script.py` and a quoted mention are allow cases. Check project scope with the same command outside it, subject to other existing protections. Establish that `python` is the intended interpreter; test wrappers/absolute paths as coverage boundaries.

**Pilot success:** the scoped prohibited calls are denied despite an instruction to use them, allowed calls work, and invalid configuration is visibly degraded. Then observe one normal work session for false blocks and actor recovery, using existing logs. This establishes mechanism and usability, not a statistically measured reduction in repeated preferences. Roll back the pilot rule if it causes unacceptable false blocks; preserve existing protections. Pi is the next host only after this first result, not part of the initial approval.

**Open questions, not blockers:** actual installed versions; bypass/interactive paths; who covers local runners; interpreter exceptions; and whether product-managed retrieval improves judgment guidance enough to justify its operations. The current design **does not automate the index cap or solve ignored judgment guidance**. Revise this design for later additions rather than accumulating scripts.

**Status:** recommendation and tests proposed; nothing installed or executed. Brian approves pilot scope; Claude owns upkeep. [Product source reading](systems/cc-safety-net.md).
