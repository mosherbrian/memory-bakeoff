**My recommendation (medium confidence):** use existing editable guidance and recoverable history. Agents can infer a useful scoped rule from examples already encountered, rather than waiting for Brian to formulate every rule. Keep it revisable and subordinate to applicable explicit directions. Reobserve current facts when useful; neither a remembered choice nor a profile establishes current truth. Judge success where the user receives the result. Add automation for a demonstrated gap in capture, correction or delivery, not because a benchmark used a sophisticated store.

The remaining decision is operational: which failures actually cause Brian to repeat himself—missed capture, missed delivery, wrong inference, stale scope or failure to apply?
