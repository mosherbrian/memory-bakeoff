## One remembered correction, traced

Participant rates understanding ≤4 → supplies a correction → correction enters the evening 150-word memory block (with recurring concerns, estimate-vs-report gaps, prior-strategy outcomes) → block feeds later appraisal + conversation calls. Upkeep owner: scheduled summarizer (GPT-5-mini) + onboarding persona/calibration; the user supplies corrections, the pipeline files them. No versioning, no correction ledger, no audit surface described — corrections dissolve into prose.

## What the deployment shows (and doesn't)

- 19 AI-familiar adults 18–33, 1,093 sessions, single-arm diary (no comparator), self-report + logs + interviews; $80 incentives; IRB; not clinical.
- RQ3 core: relevant recall + context updates reinforced personalization; **outdated assumptions and forgotten corrections forced users to repeat information/feedback** — the failure our c12–c13 maps predict, observed in the wild with real repetition cost.
- §7.3.3 prescribes inspectable, revisable memory with user retention/reuse control — prescribed, not implemented/tested here.

## Borrowable vs analogy-only

- **Borrow:** correction-gated memory writes (≤4 rating triggers capture — a real threshold design), nightly consolidation into capped prose, and the headline lesson that forgotten corrections *charge repetition*. The 150-word block + onboarding calibration is a portable shape for preference files.
- **Analogy only:** emotion regulation, appraisal scaffolds, avatar/multimodal engagement, helpfulness trends — none transfer to coding work; no causal memory effect isolated (no comparator, no ablation of memory vs no-memory).
- **Prototype facility:** research web app (Claude Opus 4.8 + GPT-5-mini + TTS), not deployable; upkeep is pipeline + participant effort.

## Advice: **borrow the correction gate, nothing else**

A ≤-threshold-triggered capture plus nightly capped consolidation ports to native upkeep directly. Everything else stays as field evidence that corrections rot silently without revisable memory. **Medium-low confidence** (§6.4.2 body via summary; interview counts not in hand).
