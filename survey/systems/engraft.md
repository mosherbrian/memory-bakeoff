# ENGRAFT — durable-fact overlay, not a current memory tier

Tern · cycle87 ·26September2026. **Watch; worth one bounded post-booking research probe, not deployment or a gufo port now.** Its useful distinction is fact-specific parameters surviving an empty context without prompt tokens. Its weak point is whether ordinary questions activate the right rows. No training, install, model load or GPU test performed; source clones and JSON arithmetic only.

**Mechanism.** Gradient descent changes selected n-gram lookup vectors; transformer parameters and GGUF bytes remain unchanged. The `.pleo` file substitutes rows at gather time. Omit the overlay to restore base row lookup; this is whole-overlay rollback, not per-fact deletion or supersession. The learned table rows are parameters even though the authors distinguish this from transformer weight fine-tuning. Zero added fact-context tokens is not zero compute, storage or write cost. N-gram activation bypasses an explicit retrieval decision but supplies no guarantee of a correct answer.

**Fit.** Only unusually stable, non-secret identity facts are candidates; running state, addresses/ports, model versions, assignments, preferences and procedures stay in observable/configured sources. Keep canonical text authoritative even for durable facts. A later explicit correction must override an overlay belief; otherwise persistence becomes the stale-memory failure already seen in the survey. Loading an overlay is not preference delivery, enforcement or protection. Same-host facts and phrasing diversity deserve stronger tests than isolated invented names.

**Decision.** Context-injected20-fact text is the simpler incumbent. Reserve one experiment after booking and separate execution approval, with a same-runtime injected baseline, sealed free-chat tests, sibling-fact controls, correction override and measured write cost. If a supported public path cannot fit the bounded setup/write budget, park the candidate rather than creating a gufo integration project. A fork-only result cannot establish benefit for Cairn's deployed gufo runtime. [Proposed experiment](../proposals/engraft-durable-facts-pilot.md). Confidence high in inspected mechanism and runtime mismatch, medium-low in useful fleet recall. Matrix: new row; no existing requirements2–5 upgraded.
