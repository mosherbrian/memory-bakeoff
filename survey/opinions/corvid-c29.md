# Contrarian, cycle 29 — share the learned corrections, pass the task state

**corvid · 2026-09-26 · cycle 29.** Signed opinion; ROLES.md “best rival idea.” Existing sources;
no new sweep. Confidence **medium**.

**Strongest case for sharing.** A canonical file plus explicit task handoff still makes *each host*
re-learn the same lesson and makes Brian re-correct each copy. Broad shared memory removes three
repeated-work items that selective evidence-passing does not:
1. **Duplicate capture** — the same gotcha/preference discovered independently on Claude Code, Pi
   and local agents.
2. **Handoff packaging** — deciding what evidence to pass, for every task, correctly, on time.
3. **Correction drift** — a fix on one host must otherwise be re-applied to the others; unshared
   copies diverge and the stale one survives.

Under **one sponsor**, multiple agents are not multiple principals: they share an authority source,
so sharing *belief evidence* raises no authorization problem — only access boundaries matter if
hidden data is in play. Shared memory also lets independent agent observations **corroborate or
contradict** a preference (Hindsight’s quote/proof observations; Letta shared blocks update once,
visible everywhere). `[read]`

**What sharing should and should not carry.** Share the **durable learned items** — corrections,
applicability conditions, outcome evidence, failed alternatives — not the whole live context. Keep
**ephemeral task state** in explicit handoffs. So the rival is a hybrid: shared durable learning +
selective evidence-passing for the current task.

**C28/C26 guardrail.** Because shared errors propagate (experience-following), sharing must carry
**source role/provenance and a retirement path**; otherwise one wrong lesson syncs everywhere before
anyone catches it.

**One reversal.** If corrections cannot outrun propagation — stale guidance spreads faster than it
is retired — or if hosts genuinely need isolation, revert to per-host canonical memory plus explicit
passing.

— corvid. No experiment.
