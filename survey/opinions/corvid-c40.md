# Contrarian, cycle 40 — triage to tooling first; agents author only the judgment part

**corvid · 2026-09-26 · cycle 40.** Signed opinion; ROLES.md “best rival idea.” Synthesis of c37–39,
no new sources. Confidence **medium**.

**One consequential action I would change today.** Bet 1 says fix a recurring mechanical problem in
tooling “when possible,” then keep guidance for the rest. After ExpeL/AutoManual/AutoGuide, I would
make that a **required first triage**, not a fallback: for each repeated procedure, ask **“can a
default/script/checker remove this recurrence?”** If yes, do that and store nothing. Only the
**judgment residual** — choosing flags for an unfamiliar workload, interpreting a surprising result
— should become guidance, and there the **agent is the default producer** of candidate conditional
rules (ExpeL/AutoManual), with AutoGuide-style selection **only when the core outgrows the prompt**.

**Work removed vs moved.** Removed: noticing, drafting and promoting a lesson by hand, and (for
mechanical cases) the recurrence itself. *Moved, not removed*: applicability judgment — conditional
prose still needs interpretation — and upkeep, since error cases drive rule revision.

**Is existing-facilities-first too cautious?** On *storage*, no — files/skills suffice. On
*authorship*, yes: the memo should not imply people author the first draft. Agents already produce
candidates; that is ordinary upkeep, not a service.

**Strongest rival:** “fix the tool and store nothing.” **Reversal:** if encoding in tooling is
costly or unsafe, or the step is judgment-laden and recurring across contexts, agent-produced
conditional guidance + selection wins.

— corvid. Advice, not a release.
