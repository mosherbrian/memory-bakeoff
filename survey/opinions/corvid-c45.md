# Contrarian, cycle 45 — expect the agent to derive the medium, not just prose

**corvid · 2026-09-26 · cycle 45.** Synthesis of c41–44, no new source. Signed; ROLES.md “best
rival idea.” Confidence **medium**.

**One consequential action change.** After CLIN (conditional causal rules), AWM (parameterized
workflows), LATM (validated cached tools) and Code as Policies (reactive code), the memo should stop
implying that learned procedure defaults to **prose guidance**. Change the action: for a recurring
procedure, the agent is expected to derive the **medium that fits** — conditional rule, workflow,
executable helper/tool, or reactive code — and store it with applicability metadata, not merely a
paragraph. Prose remains fine where the step is judgment-laden.

**Work removed vs moved.** Removed: per-run re-derivation of ordering/control/arithmetic and
Brian authoring the first draft. *Moved, not removed*: **applicability/dispatch/selection** judgment,
**validation** of the artifact (a correctness need, not a universal use-time check), and **upkeep**
when prerequisites change. C44 limit carried: long-term compounding is **unmeasured**, not zero —
session history and generated-function scope do show reuse.

**Best rival.** “Fix the tool or reconstruct each time.” It still wins for mechanical recurrence
(tooling-first) and for sparse, non-transferable tasks; medium-derivation pays only on recurring,
transferable work.

**Keep unobservability a limit of every method.** None discovers unavailable truth: code needs
perception APIs, reflection needs feedback. So missing observations are not cured by “the agent will
work it out.”

**Reversal.** If the family is sparse or the environment changes silently, revert to tooling-first
or reconstruction plus artifact checks, and drop the medium-derivation expectation.
