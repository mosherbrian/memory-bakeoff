# Cycle73 — current-host rival to the optional Letta trial

Tern ·26 September2026 ·all three reports incorporated; cycle complete. No probe, installation or migration.

**Corvid: accept the migration-cost challenge and default.** Keep the one-project guard pilot on the current host as the first choice. Runtime setup, authentication, integration and memory ownership are costs; the optional Letta week needs to justify them. Independent triggering does not make inferred revisions correct.

**Qualify the proposed mechanism.** Current documented triggers are step-count/compaction events, not evidence of a nightly schedule. Protected files and enforced memory budgets also reduce diligence dependencies; background triggering is not the sole benefit. MemFS does not repair Claude Code's existing index in place, but its validation and compilation path can address the corresponding delivery-bound problem inside Letta, subject to the explicit layout/limit qualifications in the assessment. Absence of a demonstrated command-enforcement path is a limit of this memory proposal, not an exhaustive finding about everything Letta can do.

**Reject migration equals accretion.** A coherent replacement harness can reduce integration work even though switching has costs. Brian's design constraint requires named components, contracts, owners and tests; it does not forbid a runtime change. There is no evidence that the proposed week's duration would all be migration time or necessarily displace the guard pilot. That is an opportunity-cost concern, not a measured fact.

**Acceptance observation retained, outcome wording corrected.** A triggered worker should commit a correction and the harness should put it into a later active decision context within the configured load budget, without the acting agent initiating upkeep. This establishes the delivery path; it does not establish that an ignored lesson now governs behavior. Appropriate later action and out-of-scope non-application remain separate checks already in the one-page design. No added framework, new approval gate or standing audit.

**Kiln:** the README-level AML card supplies a versioned Add/Search evaluation contract and a fixed answer-side comparison claim. Mark infrastructure explored at that depth, not reproduced; exact model/budget configuration remains per-contract. Private scoring material and platform review are not independent realistic-benefit evidence for a submitted memory product. No product capability row follows from a leaderboard's existence. Cairn's completed reading is incorporated below.

**Decision:** default guard/native arrangement and optional Letta week unchanged, medium confidence. Corvid's migration-cost dissent remains live; the delivery observation is a useful pilot check, not a prerequisite to recommend the already specified pilot.
