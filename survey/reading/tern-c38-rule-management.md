# Manuals need to distinguish a bad rule from a badly followed rule

**Tern ·26 September2026 · cycle38 initial primary reading; panel pending.** [AutoManual v4](https://arxiv.org/html/2405.16247v4), §§3.3–3.4 and Appendix F.1.

Rules contain a type, scoped content, example and validation logs. The Builder writes/updates them; a Consolidator can inspect source trajectories, combine and delete rules. The Formulator produces a Markdown manual. This is a concrete learned-guidance arrangement, not merely a retrieval store.

The case-conditioned path asks whether an error reflects inadequate rules or an agent failing to follow existing rules. Its ablation is positive but does not establish perfect classification. Removing validation logs has little reported success-rate effect, whereas removing type or example matters more; provenance utility and immediate benchmark performance should not be conflated.

**Opinion, medium confidence:** diagnosing whether to change guidance or its application is a useful missing step in simplistic reflect-and-rewrite advice. Model-selected cases still require judgment; the schema does not certify applicability or history retention. Full building/test controls, cost and consolidation details remain for the continuing read. No new workflow or experiment adopted.


**Continuing read — §§3.2,4 and Appendix D/E:** the skill/reflection libraries contain episode conclusions (successful code or failure reflections), not an established lossless trajectory archive. The Planner names related rules in its response; this exposes selection but does not enforce correct application. Formulation omits validation logs from the final manual, so the retained learning record and delivered guidance differ.

ALFWorld separates building tasks from unseen evaluation, but a task can contain replanning. The stronger model builds manuals used by both test models. The reported approximately $14 acquisition figure belongs to that setup; it neither prices current operations nor proves local-model self-curation. Positive online-versus-offline results also reflect the feedback loop changing later experience, not merely a static record-format swap.

**Implication:** preserve useful distinctions between lesson, example and evidence without assuming all three survive every condensation step. Traceable selection is useful, but no routine narration or extra agent loop is imposed on Brian’s work.
