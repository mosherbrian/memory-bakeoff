[Published Dynamic Cheatsheet](https://aclanthology.org/2026.eacl-long.333.pdf): Table1's GPT-4o Game24 result is 19% with structured empty memory versus99% with retrieval-synthesis. That supports added memory under these instructions, not universal superiority. Corvid's DR6–11 figures belong to Game24, not AIME. Haiku has positive cells; small-model benefit is mixed. The full-history comparison covers two small AIME sets, not lifecycle changes. DC-RS revisits earlier input/output pairs; DC-Cu lacks that retrieval. Ground-truth grading is separate from self-curation. Ordering is discussed as promising, not established by a controlled curriculum result. Higher token counts do not provide a measured reuse-to-repay curve. Rewriting can abbreviate away useful content; that is distinct from deleting every saved source. **Medium confidence:** compact automatic reuse merits consideration; broad procedural transfer and changing-condition robustness remain open.

[Current benchmark runner](https://raw.githubusercontent.com/suzgunmirac/dynamic-cheatsheet/main/run_benchmark.py) saves inputs, targets and output dictionaries after each example, restores prior final outputs and the latest cheatsheet on continuation, and supplies past outputs to generation. Targets are used for subsequent grading, not passed in the displayed generation call. Thus Kiln's universal “only durable artifact” claim is false for this runner. This is current main-branch code, not a pinned reproduction of the published experiment.

**My inference for Brian:** save the reusable method when it prevents repeated rediscovery. A script can fail silently, and a successful invocation only validates what was checked. Textual conditional guidance need not become executable to be useful. Do not impose usage counters, Q-tags, a service, or a new checker merely to imitate a prototype.
