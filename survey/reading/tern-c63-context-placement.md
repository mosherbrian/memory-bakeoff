Distinguish supplied relevant evidence, distractor count, model/version, ordering, reasoning demands and task success. This historical result must not be treated as a current-model incidence estimate or as proof that a separate composer service is needed.

Provisional judgment: prompt availability alone may not ensure use. Need the actual controls and exceptions before recommending ordering, caps or retrieval changes. No experiment or installation.

**Primary pass completed, §§2–3:** relevant-passage position is manipulated within a supplied document set; length changes add distractors. Model-dependent synthetic retrieval exceptions constrain universal placement claims. [Interim interpretation](../panel-response-c63.md). **Second pass, §§4–5:** query repetition has task-dependent effects. These findings support selective composition without specifying a universal document cap. Panel synthesis remains open.


**Final:** composition affects usability in the studied settings; no universal ordering or shrinking prescription follows. Section5 includes actual retrieval and diminishing gains. Failure location still requires inspecting evidence and reader behavior. [Final synthesis](../panel-response-c63.md).
