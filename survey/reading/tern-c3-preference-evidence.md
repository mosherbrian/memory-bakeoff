# Preference memory: availability, use and authority are different

**Tern · cycle 3 · 26 September 2026.** Primary methods and limitations reading; no reproduction. Brian's stated preference-repetition cost supplies relevance, not a benchmark score.

| Source | What it tests | Decision-relevant boundary |
|---|---|---|
| [Know It, Act on It](https://arxiv.org/html/2607.29433v1), §§3–4 and appendices C–E | Independent paired recall and contextual-response tests on the same preference, with synthetic personas and model judging. | Useful separation of available knowledge and use. Target updates and forget requests are removed, so this is not a supersession test. A response judged more preference-aware than a no-memory baseline is not a tool-execution outcome or proof of the model's internal state. **Medium relevance; strong confidence in that scope.** |
| [PAHF](https://arxiv.org/html/2602.16173v1), §§3–5, appendix B | Explicit user memory, pre-action questions and post-action correction, including preference shifts. Evaluation includes simulated human feedback and no-memory/single-feedback-channel controls. | Supports treating correction as part of learning, not just adding facts. Human attention cost and mistaken feedback remain important limits; this does not justify repeatedly asking Brian what he has already said. **Medium confidence in the mechanism's relevance.** |
| [Memora / FAMA](https://arxiv.org/html/2604.20006v1), metric and limitations | Simulated long histories with memory creation, change and deletion. FAMA combines current-memory criteria with penalties for obsolete information. | The previously unresolved identity is located: this is a separate work from Supersede. It tests currency alongside use, not just recall. Its weighted aggregate is not a universal utility score for Brian. **High confidence in identity and metric distinction; medium transfer.** |

**My recommendation, medium confidence:** keep explicit directions and inferred tendencies distinguishable. A recurring correction from Brian should update the authoritative record and its loaded views; do not leave it buried in a chat or require manual re-entry on every host. Inferred low-stakes style can remain tentative and context-sensitive. An artifact can disprove a factual assumption but cannot decide whether Brian still wants concise answers or full research pace. The executive must reconcile feasibility with his direction, not silently substitute one for the other.

**Illustrative case from this conversation, not an experiment:** the survey's scheduled pause satisfied a liveness schema but violated Brian's continuous-work preference. The correction changed the standing rule and actual dispatches. This exposes interpretation and application as well as storage; it does not establish which memory product would have prevented the mistake.

The minimum arrangement should avoid making Brian curate every inferred preference while making repeated explicit instructions durable.
