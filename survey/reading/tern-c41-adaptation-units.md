# Adaptation includes capability variation, but not yet arbitrary rule drift

**Tern ·26 September2026 · cycle41 initial primary reading; panel pending.** [CLIN v1](https://arxiv.org/html/2310.10134v1), §§3.2–3.3 and4.

The evaluation separates repeated trials in one reset environment, transfer to a new configuration and transfer to a new task. Text memory updates from trial feedback; meta-memory generalizes selected prior memories for a target task. Scores are simulator rewards, so do not relabel every point as success-rate improvement.

A concrete qualitative case changes a stove from working to broken and uses a lighter instead. That is more consequential than location variation alone and is relevant to prerequisites; it is not, by itself, a controlled longitudinal software-version drift experiment. The source also acknowledges failures when generalized advice has differing initial conditions.

**Opinion, medium confidence:** this is a useful challenge to claiming our literature has no changed-capability examples. The remaining question is whether the reported controls isolate safe revision of previously valid guidance, versus recovery or transfer among known variations. Causal sentence forms are learned hypotheses, not identified causal laws. Feedback, trial budgets and source retention remain for the continuing read. No experiment adopted.


**Continuing read — controller and failure analysis:** §3.1 explicitly selects memory from task/history before goal generation; this is not an invented selector despite the panel's loose “task manager” label. §4.3 reports a memoryless controller ablation and a separate memory-format ablation, so overall advantage cannot be assigned to memory alone. Its gallium example has suitable alternative guidance available but wrong stove guidance repeatedly selected. Corrective evidence can be present without winning action selection. This supports targeted diagnosis, not a required new monitoring service.
