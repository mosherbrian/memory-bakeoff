# Preference prediction, action grounding and local memory

**Tern · 26 September 2026 · primary reading, no experiment.**

**ReaLMem / ChronoProfiler** ([methods and ablations](https://arxiv.org/html/2609.19167v1)) uses seven contributors’ personal media and annotations, with generated narrative and owner-checked evaluation. Authentic source data does not make the downstream ranking exercise an interactive adaptation study. The temporal-stability ablation helps profiling more consistently than assistance; occasion-specific assistance falls across the tested readers. This makes temporal evidence relevant, not a universal replacement for contextual interpretation. The compact inference prompt does not establish low lifetime cost: profile construction and upkeep are separate. Nor does the instruction against inventing narrative establish perfect fidelity. **Medium confidence:** weight habitual evidence as a revisable prior for prediction, not as authority over a current explicit request. The paper does not compare that authority policy or measure repeated correction burden.

**Mem2ActBench** ([§§3–5](https://arxiv.org/html/2601.19935v1)) measures parameter grounding from historical information under underspecified requests; main comparisons supply the correct tool. Query generation can explicitly refer to earlier preferences, so retrieval need is not invariably uncued. Oracle evidence raises F1 substantially but leaves considerable error: this diagnoses retrieval headroom without eliminating composition/reasoning limits. A discriminator’s failure is a filtering criterion, not proof that no model could infer the answer without memory. **Medium confidence in relevance to application, limited procedural-transfer evidence.** Tool-call prediction is distinct from executing and verifying the real-world result. Do not read these two benchmarks as the entire procedural literature or infer a universal absence of transfer.

**MemOS local plugin** ([actual plugin README](https://raw.githubusercontent.com/MemTensor/MemOS/main/apps/memos-local-plugin/README.md)): local SQLite and host adapters are concrete. The DeepSeek Harness adapter defaults to the host’s provider/model for auxiliary LLM calls; configured providers therefore determine whether inference leaves the machine. Missing configuration can preserve lightweight traces while skipping/degrading LLM-dependent evolution. **Watch, medium confidence in documented mechanism, unknown operational value:** local storage, local inference and complete learning functionality are different claims. No installation, provider change or acceptance of the top-level README’s blanket on-device framing.
