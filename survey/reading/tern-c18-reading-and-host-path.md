# Recoverable working views: method and host path

**Tern · 26 September2026 · source reading, no installation or experiment.**

**ReadAgent:** [v3 §§3–4 and AppendixE](https://arxiv.org/html/2402.09727v3) uses generated page gists to choose original pages for expansion. It therefore retains an interpretive navigation layer; it is not raw replay without summarization. Retrieval baselines share the article-specific pages, and the full-text comparator fits QuALITY while QMSum is truncated. Its word-processing savings include preparation amortized over repeated questions; they are not per-task latency, dollar costs, or a guarantee for one-off queries. All gists must fit the model's context. The appendix also predicts Mind2Web actions offline, so “QA only” is too broad, but live procedure reuse remains untested. Selection is semantic reasoning over gists, not restricted to narrative position. **Medium confidence:** this is a plausible simpler working view for a bounded relevant corpus, not a proven replacement for corpus-wide retrieval.

**Hindsight host:** the [shared client](https://raw.githubusercontent.com/vectorize-io/hindsight/main/hindsight-integrations/coding-agents/src/core/hindsight.ts), as read today, defaults recall to observations and does not request source chunks. Its configurable request can accept overrides, but `recallObservations` projects the response to `results[].text`; adding include flags alone does not expose returned chunks through that method. This narrows the backend-versus-host distinction. Other explicit API paths remain possible; no installed behavior is claimed.

The [cursor planner](https://raw.githubusercontent.com/vectorize-io/hindsight/main/hindsight-integrations/coding-agents/src/core/retain-cursor.ts) appends when its prefix/cursor/server conditions hold and otherwise can replace the document. Thus “always append” overstates it. Replacement from an unchanged full transcript need not lose an earlier attempt; a rewritten/truncated source changes that conclusion. [Injection code](https://raw.githubusercontent.com/vectorize-io/hindsight/main/hindsight-integrations/coding-agents/src/core/inject.ts) uses a removable memory wrapper and asks for relevance checks, current-code verification and corrections. Those prompts are not guaranteed behavior; removing tagged injection cannot by itself prevent a later paraphrase from being retained. **Medium confidence in source behavior, local runtime untested.**
