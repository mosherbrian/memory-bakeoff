# Cycle58 — acquisition has a control, but it is not all on demand

Tern ·26 September2026 · complete: all three panel pieces and Corvid's addendum read. [Independent methods](reading/tern-c58-os-copilot.md), [OS-Copilot v2](https://arxiv.org/html/2402.07456v2).

**Corvid:** accept allowing agent-created helpers when useful; our baseline already does. The choice of what to author and retain moves to generator/critic rather than disappearing. Separate tool creation on a retrieval miss from self-directed practice under a supplied learning objective. GAIA compares development-set acquisition against the same framework without that learning: gains4.30/2.52/0 points across levels, not the35% relative cross-system headline. This supports the acquisition bundle without fully isolating stored code from every other retained effect. Do not call admission cheap without cost evidence or require a pre-built library as our baseline. [Opinion](opinions/corvid-c58.md).

**Kiln:** accept the curriculum as a candidate for a named missing competence. The objective and—in the spreadsheet setting—the intended package are supplied, even if practice tasks are generated. Four initial tools and OS interfaces are scaffolding; the score>8 rule is a heuristic about reuse potential, not a calibrated correctness guarantee or uniquely the only admission condition. Distinguish critic-judged completion from benchmark evaluation. Do not infer a frozen test-time repository from development/test separation without an explicit restriction. The paper reports answer times, although total acquisition/upkeep remains unpriced and nearby time prose conflicts with its table. No need to import Cradle's code-check details into this implementation. [Card](systems/os-copilot.md), [opinion](opinions/kiln-c58.md).

**Advice:** use demand-driven authoring or bounded practice where an actual skill gap makes either worthwhile; neither is mandatory. Ask whether existing tools or a pointer to the right interface already cover it. Retention remains selective and outcome judgment fallible. No curriculum, threshold, helper or runtime is deployed by this recommendation. Medium confidence.

**Corvid addendum:** accept the within-framework versus cross-system distinction and the missing acquisition ledger. “Only” should not erase the positive acquisition result; practical importance depends on its cost and task. Narrow “goals and supervision supplied”: the learning objective is supplied, while the agent proposes practice tasks and the critic evaluates them; that is not supplied ground-truth supervision. Helper creation/admission/revision is not inherently an unsupplyable competence—humans or existing tools can provide it. The actionable condition is an actual gap worth learning under the given objective, not an opposition between supplied capability and agent invention. [Addendum](opinions/corvid-c58-addendum.md).

**Cairn:** accept the useful within-framework learning controls. They isolate prior acquisition more closely than the cross-system comparisons, but not necessarily code-library content alone from other retained effects or test-time generation. Admission includes a reuse-potential score>8 as well as judged completion, not only a success verdict. The Excel package-choice explanation is supported by the reported baseline behavior but not separately varied; it cannot establish a universal moderator or “largest gain in the corpus.” Same-application transfer is valuable without being cross-application transfer. No tested local executor here. Answer-time measurements exist, including the table/prose discrepancy recorded in the lead note; total acquisition cost remains unpriced. Do not turn10 tasks/8 tools into an expected recipe or budget for Brian. [Reading](reading/c58-os-copilot.md).

**Memo change:** name bounded practice as an option for a missing competence, alongside existing tools and interface guidance. This is conditional advice supported by acquisition results, not a release to run experiments. Next CRAFT: does answer-grounded tool validation and abstraction add evidence beyond a critic's reuse score? One primary source, no deployment.
