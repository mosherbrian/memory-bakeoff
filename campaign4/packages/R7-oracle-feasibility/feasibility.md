## Why this is FEASIBLE_PREREQUISITE, not NO_GO

The 70 remaining findings are exactly the documented inventory defect (79
discovered names, mostly filename stems, headings and technology words;
date-stem names are additionally unsatisfiable alongside short forms, since
any stem-titled section also matches the short name and trips the shared
rule). Every content check the fixture can satisfy is satisfied, proven by
the negative varying only content. The independent behavioral criterion for
a later repair is therefore concrete: the repaired gate must accept this
exact fixture with exit 0 and no new findings, while keeping the negative
red. A broken gate need not pass now; the expected current failure (only
inventory findings) vs the unproven future exit 0 are distinguished above.
